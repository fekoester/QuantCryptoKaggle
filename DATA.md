# Data

This repository does not version the Kaggle competition data.

Download the files from the Kaggle competition page:

https://www.kaggle.com/competitions/g-research-crypto-forecasting

Place the extracted files under `raw/`:

```text
raw/
  asset_details.csv
  train.csv
  supplemental_train.csv
  example_test.csv
  example_sample_submission.csv
```

The scripts only require `raw/train.csv` and `raw/asset_details.csv` for the
offline validation experiments documented in the README.
